Formularios en HTML






Contacto

campo especializados para datos de contactos: contraseña, correo electrónico, teléfono y URL, cada uno con su propio teclado y validación en el navegador.





Númericos

Campos para valores númericos: un número con limites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha y hora combinadas, hora, semana del año y mes.






Selección

Controles de selección: elegir un color, marcar una casilla, elegir una opción de un grupo de radios y subir un archivo.





Lista desplegables (select)

Lista desplegables con el elemento select: Una opción simple, una con un valor preseleccionado (selected), una agrupada con optgroup, una de selección múltiple (multiple) y una deshabilitada (diabled)
